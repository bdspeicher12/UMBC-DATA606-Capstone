# App

Source code for the interactive web application that serves the trained model.

## Contents

*The application will be added later in the semester (Assignment 4).*

## Planned Stack

- **Streamlit** — for the user interface
- The app will load the trained model and let users enter a hypothetical film's attributes (budget, genre, runtime, release timing, etc.) to receive a predicted box-office success probability.

## Running the App (once built)

```bash
pip install -r requirements.txt
streamlit run app.py
```
